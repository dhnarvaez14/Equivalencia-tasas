    Qué significa que dos tasas sean equivalentes

    Dos tasas son equivalentes si, con el mismo capital y el mismo plazo, producen el mismo valor futuro.

    (1 + i₁)^n₁ = (1 + i₂)^n₂

    n₁ y n₂ son los periodos de cada tasa dentro de un mismo año. La equivalencia se obtiene potenciando; la tasa nominal es la única que se divide entre m.

    Nominal → Efectiva

    i = j / mE.A. = (1 + i)^m − 1

    Ejemplo: 24 % NMV → 2 % mensual → 26,82 % E.A.

    Efectiva → Nominal

    i = (1 + E.A.)^(1/m) − 1j = i × m

    Ejemplo: 30 % E.A. → 2,2104 % mensual → 26,53 % NMV.

    Efectiva → Efectiva

    (1 + i₁)^n₁ = (1 + i₂)^n₂

    Ejemplo: 30 % E.A. → 1,30^(1/4) − 1 = 6,78 % E.T.

    Nominal → Nominal

    i₂ = (1 + j₁/m₁)^(m₁/m₂) − 1j₂ = i₂ × m₂

    Ejemplo: 24 % NMV → 6,1208 % trimestral → 24,48 % NTV.

    Anticipada ↔ Vencida

    i_v = i_a / (1 − i_a)i_a = i_v / (1 + i_v)

    Primero se pasa a vencida; luego se aplica el caso que corresponda.

    Notación

    NMV = Nominal Mensual VencidaE.T.A. = Efectiva Trimestral Anticipada

    m: periodos de capitalización por año (mensual 12, trimestral 4, semestral 2). La periodicidad diaria usa 365 días.
